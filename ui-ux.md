Kava Community Hub: UX/UI Design System & Specification1.0 Core Design PhilosophyThe app's design philosophy is "Warm Minimalism." This is a fusion of two distinct concepts:Minimalist Structure (The "Chassis"): The app's layout, component structure, and user flow will be based on the "BrewNow" reference (Images 1-4). This aesthetic is defined by its clean, uncluttered interfaces, generous use of negative space, and a focus on reducing cognitive load.1 Every element must have a clear purpose.1Warm Kava-centric Theme (The "Vibe"): The app must not feel sterile. It must evoke the "kava bar" atmosphere, which is "warm," "cozy," "communal," "natural," and "relaxing".3 This theme is applied via a specific color palette, typography, and imagery.The final product should feel like a premium, modern, and intuitive application that is also a welcoming digital "social hub".92.0 Global Design System (Design Tokens)This system defines the atomic-level rules for all components to ensure visual consistency.2.1 TypographyFont Family: A single, premium, geometric sans-serif font (e.g., Inter, Poppins, or similar).Hierarchy: Hierarchy must be established primarily through font weight (e.g., Bold, Medium, Regular) and size, not through a wide variety of colors.10Readability: All body copy must be optimized for legibility on mobile devices.112.2 Color Palette ("Warm Minimalist")This palette is a strict override of the cool blues and blacks seen in the "BrewNow" reference (Images 1-4).PaletteUsageColor Specification (Examples)PrimaryPrimary CTAs (Buttons), selected states, key accents.Deep Olive Green, Terracotta, or a warm Earthy Brown.AccentSecondary highlights, special notifications (e.g., for rewards).A complementary warm tone (e.g., Warm Gold, Muted Orange).Neutrals (Light Mode)    BackgroundMain app background.Warm Off-White or Light Sand (e.g., #FBF9F6).    Text (Body)Primary text.Deep Charcoal or Dark Brown (e.g., #333333). This prevents a cluttered feel and guides the user's eye.1Grid: All layouts must adhere to a consistent grid (e.g., 8pt grid system).Thumb-Friendly Design: All primary CTAs (e.g., "Pay Now," "Add to Cart") must be "thumb-friendly" — large, high-contrast, and placed in easily accessible zones at the bottom of the screen.122.5 ImageryStyle: All lifestyle and hero imagery must be high-quality and professional.Content: Imagery must reflect the "community" and "social hub" identity.9 Prioritize photos of people connecting in a cozy lounge, community events, and relaxing a-tmospheres, not just isolated product shots.73.0 App Architecture & Navigation3.1 Primary NavigationComponent: A persistent, native bottom tab bar.Structure: The tab bar must contain the following four (4) items in this specific order:Home: Landing screen, discovery, and rewards summary.Rewards: Main loyalty program "wallet" and redemption center.Cart: Order summary and checkout entry point. Must support a "badge" overlay to show item count.Profile: Account settings, order history, etc.3.2 Core User FlowsStandard Ordering Flow:Browse: User selects an item from the Home Screen (Image 3) or a menu list.Configure: User makes selections on the Product Detail Screen (Image 2).Add Item: User taps "Add to Cart."Feedback: Floating Cart Bar (Spec 4.2, based on Image 5) animates in, providing immediate confirmation.13Review: User taps the bar or the 'Cart' tab to go to the Cart Screen (Image 2).Checkout: User taps "Continue" and moves to the Checkout Flow (Image 1).Pay: User completes payment. Floating Cart Bar is dismissed.Rewards Engagement Flow:Discover: User sees their points summary on the Rewards Widget (Spec 4.1) on the Home Screen (Image 5).Explore: User taps the "View Rewards" CTA.Navigate: App navigates the user directly to the Rewards Tab.Engage: User explores redeemable rewards, tiers, and badges.154.0 Key Component Specifications (Mandatory)These two components are non-negotiable and must be implemented precisely as specified, based on the functional requirements from the Dunkin' reference (Image 5).4.1 Home Screen: Rewards Summary WidgetReference: Functionally based on the loyalty widget in Image 5.17Position: On the Home Screen, placed prominently below the header/greeting.Aesthetic: Must be styled using the "Warm Minimalist" design tokens (Section 2.0).
